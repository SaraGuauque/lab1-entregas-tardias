# Datos de trabajo

Los archivos CSV reales de Olist se descargan automaticamente desde una revision fija de GitHub al ejecutar el notebook.

- No copie los archivos grandes al repositorio.
- Si trabaja sin conexion, descargue los siete CSV indicados en `docs/Guia_Olist_S12.html` y configure `OLIST_DATA_DIR` para apuntar a esa carpeta.
- El archivo JSON real de ID 17 se crea en `reports/` al finalizar con datos reales.

No se incluyen datasets de demostracion, falsos ni datos de otros estudiantes.
